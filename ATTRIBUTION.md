# Asset attribution

Every non-code asset in this repository (images, icons, fonts, example drawings, presets) is listed
here with its author, source and licence. The gate (`factory attrib miter`, also run by `factory verify`)
fails if an asset file is missing from this table.

**Policy (mandatory):** no iconography, images, artwork, fonts, hatch/pattern libraries, linetypes,
templates or presets copied from third-party or proprietary reference products. Every asset is
original work by MITER contributors or third-party material under an open licence.
